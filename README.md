## 🛠️ Requirements & Tech Stack

* **Core Language:** Python / C++ *(Keep the language you used for these algorithms)*
* **Libraries (for CV programs):** OpenCV, NumPy, GTK (if applicable for user interface)
* **Environment:** VS Code / Terminal 

## 💻 How to Clone and Run

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the target directory (e.g., Dijkstra):**
   ```bash
   cd Dijkstra
   ```

3. **Execute the program:**
   ```bash
   # For Python
   python dijkstra.py
   
   # For C/C++
   gcc dijkstra.c -o dijkstra && ./dijkstra
   ```

## 📊 Performance Analysis
Each core algorithm folder covers:
* **Time Complexity:** Analysis of Best, Average, and Worst-case bounds (e.g., $O(V^2)$ or $O(E \log V)$ for Dijkstra).
* **Space Complexity:** Evaluation of auxiliary memory usage.
